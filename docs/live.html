Ecosystem Supervision Features

The dashboard introduces active oversight and compliance tools for your team

Real-Time WebSocket Stream
Every log line, prompt, and intermediate agent choice is piped in real-time to your dashboard via Elixir PubSub. Watch agent trajectories on any device.
Active Command Injection
Supervise sessions live. Send strings to stdin, approve planner steps, or inject shell signals (SIGINT/SIGKILL) to stop runaway loops immediately.
Automated PII Redaction
Our streaming engine automatically redacts API keys, credentials, or personal information before they are visualized or persisted, ensuring full compliance.
GitOps Convergence Policy
Declare agent execution constraints and safety schemas centrally in a `agentops.yml` manifest file. The backend automatically boots custom dynamic VM pipelines to enforce them.
Detailed Cost Metering
Track token usage, cost analytics, and active budgets per developer, host bridge, or session, preventing surprises on your LLM API accounts.
Audit Logs (SOC2)
Centralized access history logs detailing who ran which tasks, accessed which repos, and modified which files, ready for external compliance reviews.
