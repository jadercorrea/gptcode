# Support

GPTCode is an independently maintained open-source project.

- Use [GitHub Discussions](https://github.com/jadercorrea/gptcode/discussions)
  for usage questions, ideas, and architecture conversations.
- Use the
  [bug report form](https://github.com/jadercorrea/gptcode/issues/new?template=bug_report.yml)
  for reproducible defects.
- Use
  [GitHub Security Advisories](https://github.com/jadercorrea/gptcode/security/advisories/new)
  for vulnerabilities.

Before requesting help, run `gptcode --version`, identify the provider and
model involved, and reduce the problem to the smallest repository or fixture
that still reproduces it. Remove credentials and proprietary code from all
public reports.
